⚔ Action Configuration

Each action has a base definition (applies to all players) and optional affinity overrides. When an override exists for the player's current affinity, it replaces the base values. Flex actions redirect humanity gain for Bambis based on their Discord Path Role (requires UFramework Discord integration). Path Hero role → positive gain, Path Bandit role → negative gain. Best used with EXACT or ADD action types.

EXACT — Fixed value ADD — Toward path SUB — Against path MULTIPLE — Multiply MULTIPLEADD — Multiply + MULTIPLESUB — Multiply toward 0
